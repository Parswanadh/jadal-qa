# Running many agents in parallel
1. **Inside one session**: the lead issues several `task` tool calls in ONE message (independent tasks, disjoint output folders, self-contained briefs). Subagents cannot spawn subagents (`task: "*": deny` in the subagent files). A subagent's own `permission.edit` globs bound what it can write: `.opencode/agents/docs.md` allows only `docs/**`, `experiments/**`, `*.md`, so the `docs` agent cannot create `tools/pod/*.py` with the edit tool (see RUNBOOK.md).
2. **Headless workers**: `bash tools/pod/launch_workers.sh start <name> <agent> <prompt-file> [base-branch]` creates the git worktree + branch itself (it `cd`s into the worktree), starts a private server (`--standalone`), logs to `/workspace/logs/<name>.log` and records the PID under `/workspace/state/pids/`; `status`, `stop <name>`, `logs <name>`; `stop` kills only the recorded PID. Cap `JADAL_MAX_WORKERS` — default **4** in the script, but `/workspace/env.sh` exports **6** (check `echo $JADAL_MAX_WORKERS`). Verify after 60 s that the log shows tool activity (a log with only CLI help text means invalid flags for this version).
3. **v2 CLI facts (checked on v2.0.26)**: `opencode run [flags] [message...]` with `--agent`, `-m provider/model#variant`, `--session/-s`, `--continue`, `--fork`, `--format json`, `--file`, `--title`, `--auto` (auto-approve what is not explicitly denied), `--standalone` (private server), `--server`; no `--dir` and no `--variant`. Sessions: `opencode session list`. Background service: `opencode service start|stop|restart|status`.
4. **Budgets**: A40 **46,068 MiB (46 GB)** — keep ≤ ~40 GB total across jobs; CPU load ≤ 75 % of cores (the cgroup quota is ≈7.65 cores, i.e. ≈5.7 busy cores, not the `nproc` value of 4 that coreutils prints because `env.sh` sets `OMP_NUM_THREADS=4`; see [ENVIRONMENT.md](ENVIRONMENT.md)); RAM ≤ 8 GB per process.
5. **GPU jobs**: wrap every command that touches the GPU in `bash tools/pod/gpu_run.sh <cmd> [args…]` (2 slots, `JADAL_GPU_SLOTS`); never exceed ~40 GB of the 46 GB card across jobs ([ENVIRONMENT.md](ENVIRONMENT.md)).
6. **Failure handling**: relaunch narrower; log the failure in RUNBOOK.md.
