## Ranked top-3 most adoptable (concrete sketches)

### #1 — Subsampled NSS-naturalness gate (NIQE-style, no training) → stage-0 reject
**Formula.** Per sampled frame (1 fps, luma, full-res crops or 2×2-block-averaged to bound cost): MSCN coefficients
`Ĩ = (I − μ) / (σ + 1)`, μ,σ from 7×7 Gaussian window; fit GGD to Ĩ and AGGD to 4 pairwise products (H/V/D1/D2) at 2 scales → 36-dim vector `f`. Offline, fit one MVG `(ν, Σ)` on *accepted factory* windows only. Per-frame distance `d = √[(f−ν)ᵀ ((Σ+Σ_q)/2)⁻¹ (f−ν)]`; window score `D = mean(d over 10 sampled frames)`. Reject iff `D > τ_reject` (τ from LOCO on our 150 windows, target high recall of bad); else pass to stage-1.
**Integration.** Stage-0, first op after decode, per 2-s chunk partial means → pooled at 10-s boundary; log `(ν, Σ, τ, D)` into hash-audited record. **Cost:** ~10–100 ms/window edge CPU. Deterministic ✓. Streaming ✓.
**Why first:** only no-training theory that fits our label budget; BRISQUE-36 features without its SVR keep auditability.

### #2 — Interframe-maxima keyframes + dHash sequence + extended-frame hash → stage-0 dedup/loop gate
**Formula.** Downscale to 320-wide gray; `e[t] = mean|G[t]−G[t−1]|`; smooth with fixed Hanning-30; keyframes = mid-points between adjacent local maxima (Fojcik §5.1, Hanning-30 row: μAP 0.93, targeted-blackout 0.88). dHash-64 each keyframe (8×8 gradient bits); duplicate test = **median** Hamming ≤ T_dup (T≈10–16 bits, from #9 crop/re-encode intra-stats) + duration prefilter ±5% (viddup L1/L2). Parallel: extended-frame hash = dHash of mean of each 2-s chunk (Niwa-style, n≈60 frames) → loop test across windows.
**Integration.** Stage-0 alongside #1; all constants (Hanning-30, T_dup, sample width) in audited config; SQLite xxHash cache per viddup for cross-window dedup. **Cost:** ~100–300 ms/window (decode-bound) + ~50–150 ms diff-curve + <1 ms/hash. Deterministic ✓. Streaming ✓ (per-2-s-chunk keyframes + accumulator).
**Why second:** kills wasted compute on re-uploads/replays before any quality math; robust to our exact perturbation set (re-encode ≈ free, speed-change invariant, 5%-crop inside threshold, brightness handled by gradient-hash + gray).

### #3 — TLVQM-low-complexity motion/appearance subset with fixed thresholds → stage-1 uncertain-resolver
**Formula (no SVR).** At 1–3 fps on 2-s chunks compute: motion energy `m = mean|G[t]−G[t−1]|`, motion std, jerkiness proxy `j = std(Δm)`, blur proxy = variance-of-Laplacian drop vs running baseline, noise proxy = MSCN-GGD shape shift, blockiness proxy = 8-px-grid edge energy ratio, brightness/contrast means. Each has a fixed accept/uncertain/reject band from LOCO quantiles of the 150 windows; stage-1 verdict = worst-band-wins with ties → uncertain (keeps human calibration auditable without a trained regressor).
**Integration.** Stage-1, only for windows passing stage-0 or flagged uncertain; chunk stats already partially computed by #2 (share the downscaled gray + diff curve). **Cost:** ~100–500 ms/window after shared-frontend deduction. Deterministic ✓ (quantile thresholds in config). Streaming ✓ (1-s/2-s chunk stats).
**Why third:** UGC-VQA evidence (#2, #5, #7) says motion features are the difference between 0.6 and 0.8 on shaky footage — this buys that gain without VIDEVAL's 60–350 s or any GPU DNN.

## Honest caveats
1. **NSS pristine-model mismatch is the top risk.** NIQE/BRISQUE "naturalness" is calibrated on natural photos; factory egocentric footage (low light, motion blur, uniform surfaces) is off-manifold — refit MVG strictly on accepted factory windows and re-validate LOCO; expect τ to be lenient (factory baseline is uglier than Flickr).
2. **Completely-blind models are empirically weak (#7):** NIQE ≤0.60, VIIDEO ≤0.30 SRCC on UGC — never use #1 alone as accept; it is a *reject* gate only, with uncertain doing the heavy lifting toward 0.80 AUROC.
3. **No public dataset matches egocentric factory.** LIVE-VQC (mobile, outdoor, acted motion) is the closest; KoNViD (Flickr, resized 540p) and YouTube-UGC (gaming/animation/HDR) do not transfer — treat all cross-dataset numbers as priors, our 150 windows as truth.
4. **Hash blind spots:** mirror ≈ chance and border/crop shift inter-scores (#9); targeted 1-frame/s blackout kills naive 1-fps (#11 — adopted design avoids it). Adversarial perturbations break all perceptual hashes (#13) — out of threat model, but never claim tamper-evidence.
5. **Heavy methods are baselines only:** VIDEVAL (60–1716 s), TLVQM-full, all DNNs (RQ-VQA/FAST-VQA/SimpleVQA) violate edge-cheap/NO-GPU — run offline for ceiling numbers and threshold mining.
6. **Recalled-not-fetched items (#13, #14)** rest on excerpts + secondary citations; re-verify against the PDFs before any external publication; all design decisions above depend only on fetched sources.
