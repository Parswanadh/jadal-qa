## Ranked top-3 adoptable

### #1 — Reducto/NoScope-style deterministic CPU cascade (L0 compressed-domain → L1 diff → L2 skin+motion → L3 funnel)
**Why #1:** biggest Pi win, fully compatible with hash-audit + 2-s streaming, proven 51–97% early-discard lineage.
**Adoption sketch (no GPU, deterministic):**
1. `L0 (per GOP, compressed domain):` parse HEVC MVs per 2-s chunk (`tools/hevc_mv.py`, pinned ffmpeg/ffprobe version logged); features: mean MV magnitude, % skip blocks, scene-cut flag. If `L0 < T0_still` → mark chunk still/uncertain-fast-path (skip L2).
2. `L1 (per frame-pair, RGB-lite at 160px):` motion-compensated grey diff (ORB-homography with fixed iterations, or translation-only fallback) + Sobel edge-energy; chunk score = p90 over pairs. If `L1 < T1` → accept-good-fast (no hand activity change).
3. `L2 (per chunk):` Kolkur-style CbCr skin-fraction in lower-central ROI + MOG2/KNN foreground-energy persistence; if both low → accept-good.
4. `L3:` full funnel score only on survivors → accept/reject/uncertain per 10-s window (majority/pooling over 2-s chunks).
5. Thresholds `(T0,T1,T2)` set by cost-based search on the 150 labelled windows with LOCO splits (optimise % filtered at fixed recall on bad class), frozen per deployment in `configs/threshold_card.yaml` with sha256 of code+labels+scores.
6. Drift rule (Reducto-style): if chunk feature vector falls outside labelled clusters (Mahalanobis > audited bound) → force uncertain + log, never silently filter.
**Cost:** L0 ~0 decode, L1/L2 integer ops at 160–320px; Pi-real-time plausible; deterministic yes (seed + fixed iters); streaming yes.

### #2 — Cleanlab/Datalab audit of the 150 human windows (+ 10k AI stills triage)
**Why #2:** cheapest AUROC insurance; our thresholds are only as good as 1-human labels over 7 clips.
**Adoption sketch:**
1. Build `X` = deterministic funnel features per window (no VLM, no hyperspectral), `y` = human good/bad.
2. 5-fold stratified (by wearer) cross-val logistic → out-of-sample `pred_probs` (seed pinned).
3. `Datalab(data, label_name).find_issues(pred_probs, features=X)` → `report()`; review top-ranked label issues, near-duplicates (same-clip repeats), outliers (corrupt/occluded).
4. Prune confirmed errors, reweight by confident-joint prior (don't relabel blindly); refit thresholds; record noise matrix + removed IDs in `eval/lab/lit_ego_data_edge/`-adjacent audit log (other dirs untouched).
5. Apply same pipeline to 10k AI-labelled stills to estimate AI-label noise before using them even as baseline-only data.
**Cost:** seconds on CPU; deterministic; offline (edge runtime untouched, `cleanlab` kept out of `requirements-edge.txt`).

### #3 — Classical hand-presence proxy: CbCr skin rules + manipulation-point ROI + foreground energy (no deep learning)
**Why #3:** the only non-deep ego-hand approach that survives our constraints (VLM/heavy-ML rejected).
**Adoption sketch:**
1. Per frame (320px): CbCr skin mask (Kolkur ranges, with CbCr-only fallback per Vezhnevets for harsh light) → morphology open → keep blobs in lower-central ROI, area > `A_min`.
2. Manipulation point = largest skin-blob centroid smoothed over ±5 frames (Li et al. abstraction, no gaze tracker needed); ROI = r=~20% image-width disc.
3. Foreground energy = MOG2 (history ~50, shadows off) restricted to ROI + MV-magnitude cross-check from L0.
4. Per-2s-chunk feature = persistent-ROI-energy × skin-fraction; per-10s-window = median/max pool → funnel input.
5. Calibrate `(A_min, r, persistence)` on 150 windows; add glove-failure flag (skin≈0 but motion-energy high → uncertain, not good).
**Cost:** OpenCV CPU only, per-pixel integer + GMM-lite; deterministic; streaming yes. Expect: works for bare-hand factory tasks, degrades with gloves/occlusion/wood-tones — hence gate, not decider.

## Honest caveats
- **Ego-motion breaks naive diff/background-subtraction.** NoScope/Reducto numbers come from static cameras; head-camera needs motion compensation (#1) or L1 is useless. MOG2/KNN assume slowly-varying background — violated by head turns; keep history short + ROI-gated.
- **Skin colour is not hand detection.** Gloves kill it; skin-tone bias + wood/copper confusion cause false positives; factory audit must stratify by wearer/skin-tone/glove — our 3-wearer pool is too small to claim fairness.
- **Reducto full text not parsed** (PDF binary/paywall); threshold-selection + drift-retrain details need verification before implementation. Vezhnevets marked recalled — thresholds from it are unverified.
- **Cleanlab/AL methods assume calibrated posteriors + class-conditional noise.** Our n=150 is tiny; confident joints will be noisy — use for *ranking review*, not auto-relabel; LOCO validation mandatory. CUSAL/TCM assume embedding spaces richer than ours — adapt to margin-on-funnel-score + diversity-on-funnel-features, expect smaller gains.
- **Compressed-domain MVs ≠ true motion.** Encoder QP/GOP choices distort MV energy; validate MV↔RGB-flow agreement on the 7 labelled clips first.
- **No GPU used; nothing committed/pushed.** All fetches were arXiv/PMC/docs pages + search excerpts; no keys printed; no ports touched.
