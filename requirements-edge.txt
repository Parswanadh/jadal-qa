# Minimal dependencies for the Jadal EDGE tier (B9).
#
# Edge tier = jadal.segmenter, jadal.signals, jadal.funnel, jadal.certify,
# jadal.receipts (+ jadal.config). Derived from what the import audit in
# scripts/edge_check.py ACTUALLY found in sys.modules after importing the
# edge modules (see eval/results/edge_check_*.json). Package names only, no
# exact pins from this machine (pins would bake laptop-specific builds into
# a Pi install; resolve on the target with `pip install -r`).
#
# What each package is for:
#   opencv-python-headless  video decode + L0 metrics + OpenCV colour-proxy
#                           hands/faces fallback (cv2; headless: no GUI deps)
#   numpy                   array math in signals/funnel/certify
#   scipy                   jadal.certify (exact binomial bounds, calibration)
#   pillow                  jadal.signals perceptual hash (PIL.Image)
#   ImageHash               jadal.signals perceptual hash (imagehash.phash)
#
# OPTIONAL:
#   mediapipe               hands (HandLandmarker) + faces (FaceDetector) when
#                           their .task/.tflite model files are present.
#                           mediapipe on Pi ARM64 is UNVERIFIED: the edge path
#                           must work WITHOUT it via the OpenCV colour-proxy
#                           fallback (edge_check.py proves this by running the
#                           edge path with mediapipe BLOCKED). Install it only
#                           if you also ship the model files and have verified
#                           a mediapipe run on the actual Pi hardware.
#
# torch is NOT needed on the edge. Neither are sentence-transformers,
# transformers, scikit-learn, pandas, matplotlib, fastapi/uvicorn, or any
# CUDA package. The CENTRAL tier (decision/EmbeddingGemma 2, hub, service,
# dashboard) needs those and does NOT run on the edge.

opencv-python-headless
numpy

ImageHash
