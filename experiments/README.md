# Experiment registry

Every experiment has one folder here and one line in `registry.jsonl`. The registry is append-only: the latest line for an id wins.

- `registry.jsonl`: the machine-readable log, written by `tools/exp.py`.
- `E<track>.<nn>/`: one folder per experiment, with its README (reason, hypothesis, data, regime, method, verdict) and its results files.
- `EXPERIMENTS.md`: generated by `python tools/exp.py render`. Do not edit it by hand.

Commands:

```
python tools/exp.py new    --id E1.01 --track E1 --title "..." --why "..." --hypothesis "..." --data "..." --regime "..." --method "..." --owner NAME
python tools/exp.py finish --id E1.01 --verdict adopt|maybe|drop|inconclusive --summary "..." --results path/to/results.json
python tools/exp.py list [--track E1]
python tools/exp.py render
```

Negative results are logged with their verdict. A `drop` or `inconclusive` line is as important as an `adopt`.

The protocol, and a worked example, are in `docs/EXPERIMENTS_HOWTO.md`.
